# Атлас регионов Европы

[Открыть интерактивную карту](https://robinyoter.github.io/europe-regions-atlas/).

GitHub Pages публикует ветку `main`, корневую папку `/`. `index.html` открывает автономную карту `atlas-europe.html`; `.nojekyll` отключает обработку исходников Jekyll. После правок карты пересоберите `atlas-europe.html` в корне проекта и отправьте изменения на GitHub.

Интерактивная карта: 46 стран, 456 регионов, население каждого региона. TypeScript, D3 и SVG; React отвечает за интерфейс. Приложение собирается Vinext/Vite в статический сайт.

Турция, Армения, Азербайджан и Грузия исключены из интерактивного слоя. Соседние территории отображаются серым фоном. Начальный вид показывает Европу; источник России содержит регионы всей страны. Франция представлена 13 европейскими регионами. Ватикан и Монако показаны целиком. Зависимые и заморские территории пока не включены.

Словения, Латвия, Литва, Эстония, Черногория, Северная Македония, Люксембург, Косово, Мальта, Исландия, Албания, Андорра, Лихтенштейн и Сан-Марино показаны каждая одним цельным регионом. Их внутренние границы удалены объединением полигонов. Англия разделена на 48 церемониальных графств; Шотландия, Уэльс и Северная Ирландия остаются цельными. City of London и Greater London представлены отдельно; острова Силли входят в Cornwall.

Республика Ирландия разделена на Leinster, Connacht, Munster и Ulster. В Ulster входят только Donegal, Cavan и Monaghan; Северная Ирландия не включена в ирландские полигоны и сохранена в слое Великобритании. Для группировки используются границы местных административных единиц CSO и историческая принадлежность графств.

Молдова представлена тремя регионами: «Гагаузия», «Приднестровье» и «Молдова» (остальная территория). Контуры первых двух сохранены из исходного слоя geoBoundaries; остальные полигоны объединены, включая исходную отдельную единицу Bender. Это границы исходных административных единиц, а не отдельная карта фактического контроля.

## Возможности

Румыния представлена девятью историческими регионами, Венгрия — восемью NUTS 2, Сербия вне Косово — четырьмя статистическими регионами. Чехия разделена на Bohemia, Moravia и Czech Silesia по историческим границам, пересекающим современные kraje. Для Болгарии по согласованному варианту объединены целые области в восемь географических групп; Black Sea Coast и Strandzha объединены. Кипр разделён на две части: Республику Кипр и Северный Кипр. Хорватия — на Istria, Kvarner, Dalmatia, Slavonia и Continental Croatia. Португалия — на семь регионов со скриншота, включая Азоры и Мадейру; округ Setúbal разделён между Lisboa и Alentejo. Состав, источники и методика: [CUSTOM-REGIONS.md](CUSTOM-REGIONS.md).

- Перемещение мышью и одним пальцем; масштабирование колесом и жестом двумя пальцами.
- Подсветка, название, население и год данных при наведении; выбор по клику. Флаги Германии и Украины сохраняются при наведении и выборе региона.
- Карточка с населением, датой, определением показателя, источником, пояснениями и приближением выбранного региона. Доступна по нажатию на телефоне.
- Кнопки увеличения, уменьшения и возврата к общему виду.
- Клавиатура: Tab, Enter, Escape; на карте +, −, Home и 0.
- Панель источников с датами и условиями использования.
- Детализация контуров по масштабу; части карты вне экрана исключаются из отрисовки.

Данные о населении сохранены локально в `public/data/population.json`: 406 регион за 2025 год, 9 за 2024 год, 41 с более ранними данными. У 15 регионов явно отмечен неполный охват или приближённая группировка статистики для выбранных границ. Подробности и источники: [POPULATION.md](POPULATION.md). Флагами заполнены 443 региона 46 стран; ещё 13 регионов используют пастельные заливки. Все 456 регионов получили оформление. Венгрия: флаг Будапешта и семь цветов по пользовательскому образцу. Португалия: флаги Азор и Мадейры, пять цветов для материковых регионов. Хорватия: четыре исторических флага и цвет Кварнера. Болгария: семь согласованных неофициальных геральдических композиций и приписываемый исторический флаг Восточной Румелии для Северной Фракии. Словакия использует восемь флагов самоуправляемых краёв. Греция — 13 исторических региональных или местных знамён и традиционное церковное знамя Афона; условная привязка местного флага к целому современному региону явно отмечена в карточке. В трёх регионах Финляндии временно используется национальный флаг с явной подписью в карточке. Для Германии используются обычные Landesflaggen, для Баварии — ромбы; для Украины — флаги 24 областей, АР Крым, Киева и Севастополя. Во Франции сочетаются официальные флаги, региональные логотипы и распространённые традиционные варианты. В карточке региона показан полный флаг без ссылки; Eurostat подписан обычным текстом. Флаги сохранены локально и встроены в автономный HTML. Показатели ВВП пока не добавлены.

## Локальный запуск

Рядом с исходниками сохранена автономная версия `atlas-europe.html`: откройте её двойным кликом в браузере. Карта, интерфейс, геометрия и население встроены в один файл; интернет и установка Node.js для просмотра не нужны. Ссылки на внешние источники требуют интернета.

Нужны Node.js 22.13+ и npm.

```sh
npm ci
npm run dev
```

Адрес: http://localhost:5173/. Геометрия включена в проект; во время просмотра внешние географические API не вызываются.

```sh
npm run build
```

Статический результат находится в `dist/client/`. Его можно размещать на статическом хостинге. На Windows предусмотрено корректное завершение сборщика после освобождения его фоновых ресурсов.

Создать автономную HTML-версию из этих же исходников:

```sh
npm run export:html -- ../atlas-europe.html
```

## Структура

- `app/atlas.tsx` — карта, проекция D3, наведение, выбор и масштабирование.
- `app/globals.css` — оформление и адаптация для телефонов.
- `public/flags/de/` — 16 исходных векторных флагов Германии.
- `public/flags/ua/` — 27 флагов Украины (25 SVG и 2 PNG); Николаевская область использует вариант 2026 года.
- `public/flags/fr/`, `it/`, `es/`, `pl/` — ещё 68 флагов Франции, Италии, Испании и Польши в формате SVG или стандартной PNG-версии Wikimedia шириной 1280 пикселей.
- `public/flags/at/`, `be/`, `ee/`, `fi/`, `lt/`, `lu/`, `lv/`, `nl/`, `no/`, `se/` — 83 флага четвёртого набора.
- `public/flags/by/`, `ru/` — 7 флагов Беларуси и 83 флага регионов России.
- `public/flags/gb/`, `dk/`, `me/`, `mt/` — 58 заливок шестого набора; Бристоль временно использует флаг Англии, Северная Ирландия — исторический Ulster Banner.
- `public/flags/cz/`, `ie/`, `ro/`, `ch/`, `is/` — 43 заливки седьмого набора; пять румынских флагов созданы на основе исторических гербов по выбору пользователя.
- `public/flags/ba/`, `rs/`, `xk/`, `si/`, `mk/` — 10 заливок восьмого набора; два сербских статистических региона используют согласованные неофициальные композиции на основе исторической геральдики.
- `public/flags/al/`, `ad/`, `va/`, `li/`, `mc/`, `sm/`, `cy/`, `md/`, `hu/`, `pt/`, `hr/`, `bg/` — 26 флагов девятого набора.
- `data/flags/hungary-colors-reference.png` — пользовательский образец цветов; 13 заливок записаны в `catalog.colors` и передаются в `public/data/flags.json` отдельно от флагов.
- `data/flags/catalog.json` — соответствие флагов кодам регионов, происхождение, авторы, лицензии и SHA-256.
- `scripts/prepare-flags.mjs` — проверка и сборка автономного справочника `public/data/flags.json`; автоматически выполняется перед запуском, сборкой и экспортом.

Для плавного перемещения карта использует подготовленные PNG-копии SVG-флагов, а в карточках показывает исходное изображение. Копии создаются через установленный Sharp и кэшируются по контрольной сумме SVG. Кэш автоматически восстанавливается и не входит в архив исходников.
- `public/data/regions.geojson` — геометрия и идентификаторы регионов.
- `public/data/world.geojson` — фоновый контур суши.
- `public/data/map-render.json` — подготовленные пути SVG, границы охватывающих прямоугольников и подписи; четыре уровня детализации.
- `public/data/sources.json` — происхождение геометрии и даты.
- `scripts/refresh-boundaries.mjs` — воспроизводимая подготовка границ.
- `scripts/prepare-rendering.mjs` — подготовка отображения и проверка кэша по хешу исходной геометрии и проекции; автоматически запускается перед сборкой, локальным запуском и экспортом HTML.
- `scripts/check-geography.mjs` — проверки берегов, островов, анклавов и структуры геометрии.

Справочник флагов сопоставляется с корректным `properties.isoCode` вида `FR-BRE`, а при его отсутствии — с `properties.id`. Пустые значения у итальянских регионов и повторяющийся код страны `ESP` у испанских регионов используют постоянные идентификаторы. Он может расширяться другими странами без изменения геометрии карты. Методика и источники флагов: [FLAGS.md](FLAGS.md).

Для будущей статистики используйте `properties.id` как ключ к отдельному справочнику. Также сохранены `countryCode`, `sourceId` и, где доступен, `isoCode`. Идентификаторы geoBoundaries зависят от версии источника: при обновлении геометрии понадобится таблица соответствия. Карточка выбранного региона находится в `app/atlas.tsx`.

## Географические источники

Основной источник — [geoBoundaries gbOpen](https://www.geoboundaries.org/). Для Италии выбран слой с 20 регионами, Греции — 13 регионов и Афон. В девяти указанных выше странах административные полигоны объединены в контур страны.

Дополнения:

- [Kartverket / Geonorge](https://testnedlasting.geonorge.no/geonorge/Basisdata/Fylker/GeoJSON/) — 15 фюльке Норвегии; берег обрезан по контуру суши geoBoundaries.
- [Central Statistics Office Ireland](https://geojson.cso.ie/) — границы 31 местной административной единицы, объединённые в четыре исторические провинции; цельный контур Северной Ирландии из того же набора. Принадлежность графств проверяется по [таблицам CSO](https://www.cso.ie/en/media/csoie/census/documents/census2011vol1andprofile1/Tables_1-4.pdf).
- [Ordnance Survey Boundary-Line](https://docs.os.uk/os-downloads/products/areas-and-zones-portfolio/boundary-line/boundary-line-downloads) — 48 церемониальных графств Англии; контуры Шотландии и Уэльса объединены из 35 и 8 единиц этого же набора. Названия проверяются по официальному [руководству OS](https://docs.os.uk/os-downloads/products/areas-and-zones-portfolio/boundary-line/guide-to-ceremonial-county-boundaries). Open Government Licence v3.0; содержит данные OS, © Crown copyright and database right 2026. Исходная дата границ не указана в архиве; дата получения отмечена отдельно от даты границ.
- [Research Innovation Unit Malta](https://riu.gov.mt/malta-local-and-regional-lau2/) — единый регион Мальты, объединённый из местных советов.
- [National Land Survey of Iceland](https://gis.lmi.is/geoserver/) — 61 муниципалитет, версия IS 50V от 24 сентября 2026.
- [Eurostat GISCO NUTS 2024, 1:1 млн](https://gisco-services.ec.europa.eu/distribution/v2/nuts/) — 12 округов Албании, три региона Бельгии (объединение NUTS 3 в NUTS 1), 28 областей Болгарии, 20 единиц Венгрии с отдельным Будапештом, 25 округов Сербии и пять регионов Дании (объединение NUTS 3 в NUTS 2). Для последних четырёх стран сохранены прежние идентификаторы регионов.
- [GSHHG 2.3.7](https://www.soest.hawaii.edu/pwessel/gshhg/) — контур суши из береговых полигонов L1 полного разрешения. © Paul Wessel, University of Hawaiʻi; Walter H. F. Smith, NOAA. LGPL v3 или новее; исходный архив и его контрольная сумма закреплены в скрипте. Тексты лицензий находятся в `public/data/licenses/gshhg/` и встроены в автономный HTML, доступны в панели источников. Из набора извлечена суша, геометрия упрощена для браузера и использована для обрезки административных морских зон.
- [Natural Earth](https://www.naturalearthdata.com/) — фоновые контуры стран, public domain.

Границы взяты из версий разных лет, от 2005 до 2026. Это не единый актуальный административный срез. Даты указаны в панели «Источники»; перед добавлением современной статистики нужно согласовать версии границ. Названия регионов сохранены на языке источника, цельные страны подписаны по-русски.

Административные источники могут включать территориальные воды. Для отображения регионов на суше они обрезаются береговыми полигонами GSHHG. Монако сохраняет собственный точный контур из-за малого размера. Используются полные исходники с упрощением Douglas–Peucker, порог расстояния 100 м; прежнее процентное упрощение уже упрощённых файлов удалено. Это параметр обработки, а не гарантия точности исходных границ в пределах 100 м. Для MultiPolygon ориентация каждого полигона проверяется отдельно перед проекцией D3.

Исходная геометрия сохраняется независимо от отображения. Пути SVG рассчитываются при сборке; браузер выбирает уровни с порогами 3000/1000/300 м либо исходную геометрию по мере приближения. За пределами видимой области пути не рисуются. На каждом движении не требуется заново проецировать подробные границы соседних стран. Карточка использует исходный подробный контур. Это устраняет замедление после повышения детализации; все идентификаторы и варианты деления стран остаются прежними.

Проверка наложений охватывает весь слой. На стыках национальных источников остаются расхождения, особенно с грубыми данными Беларуси 2005 года и Боснии 2013 года. Они не устранены произвольным перераспределением спорных полос. Это картографический каркас, который ещё требует согласования внешних границ для единой топологической основы; подробности текущей проверки сохранены в `BOUNDARY-AUDIT.md` и рядом с автономным HTML в `boundary-audit.md`.

Для подготовки данных заново:

```sh
npm run data:prepare
npm run data:check
```

Для подготовки нужен доступ к открытым источникам; `data:check` работает без сети. Кэш хранится в `.sites-runtime/boundary-cache/`; путь можно изменить переменной `ATLAS_BOUNDARY_CACHE`. Опциональная `ATLAS_METADATA_FILE` позволяет использовать сохранённый ответ API geoBoundaries и закрепить конкретные версии. Скрипты проверяют уникальность идентификаторов, замкнутость колец, диапазон координат WGS84, сохранение регионов после обработки, число единиц, контрольные точки на берегах, островах и в анклавах. Обновление национального источника, меняющее число регионов, требует пересмотра соответствующей проверки.

В поддерживающих WebMCP браузерах доступны действия `select_region` и `reset_map`. Их отсутствие в обычном браузере не влияет на карту.

Исландия показана одной областью выбора вместе с прибрежными островами. Население всей страны сохранено; муниципальное деление удалено только из отображения.
